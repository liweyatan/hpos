医院挂号系统数据库说明
数据库概述

数据库名：hospital_system

字符集：utf8mb4

排序规则：utf8mb4_unicode_ci

用途：支持医院挂号系统开发，包含6张表和2个视图

表结构详细说明
1. 科室表 (department)

作用：存储医院所有科室信息

id：科室的唯一编号，自动增加，是主键

dept_name：科室名称，必须填写

introduction：科室的简单介绍

sort_order：控制科室在页面上的显示顺序，数字越小越靠前

status：科室状态，1=正常可用，0=已停用

create_time：记录创建时间，系统自动生成

update_time：记录最后更新时间，系统自动更新

2. 医生表 (doctor)

作用：存储医生的详细信息

id：医生的唯一编号，自动增加，是主键

real_name：医生的真实姓名，必须填写

title：医生的职称，如主任医师、副主任医师

specialty：医生擅长的领域

dept_id：医生所属的科室ID，关联到科室表的id字段

avatar：医生头像图片的路径

status：医生状态，1=正常出诊，0=已停诊

create_time：记录创建时间，系统自动生成

update_time：记录最后更新时间，系统自动更新

3. 号源表 (registration_source)

作用：存储医生每个时间段的可预约信息

id：号源的唯一编号，自动增加，是主键

doctor_id：医生的ID，关联到医生表的id字段

work_date：医生出诊的具体日期

period：时间段，1=上午(8:00-12:00)，2=下午(13:00-17:00)

total_count：这个时间段总共可以挂多少个号

available_count：还可以预约多少个号，每次有人挂号就会减1

fee：挂这个号需要支付的费用

status：号源状态，1=可以预约，0=停止预约

create_time：记录创建时间，系统自动生成

update_time：记录最后更新时间，系统自动更新

4. 患者表 (patient)

作用：存储患者的基本信息

id：患者的唯一编号，自动增加，是主键

real_name：患者的真实姓名，必须填写

gender：患者性别，1=男，2=女

phone：患者的手机号码，也是登录账号

id_card：患者的身份证号码

birthday：患者的出生日期

create_time：记录创建时间，系统自动生成

update_time：记录最后更新时间，系统自动更新

5. 挂号订单表 (registration_order)

作用：存储患者的每一次挂号记录

id：订单的唯一编号，自动增加，是主键

order_no：订单号码，系统自动生成，格式为REG+日期+序号

patient_id：患者的ID，关联到患者表的id字段

source_id：号源的ID，关联到号源表的id字段

doctor_id：医生的ID，关联到医生表的id字段

dept_id：科室的ID，关联到科室表的id字段

work_date：患者需要就诊的日期

period：患者就诊的时间段

fee：本次挂号支付的费用

status：订单状态，0=待支付，1=已支付，2=已取消，3=已就诊

create_time：订单创建的时间，系统自动记录

update_time：记录最后更新时间，系统自动更新

6. 用户表 (sys_user)

作用：存储用户的登录账号信息

id：用户的唯一编号，自动增加，是主键

username：用户名，用于登录

password：加密后的登录密码

phone：用户的手机号码，也可以用于登录

create_time：记录创建时间，系统自动生成

update_time：记录最后更新时间，系统自动更新

表之间的关系

一个科室可以有多个医生，一个医生只能属于一个科室

一个医生可以有多个号源，一个号源只属于一个医生

一个患者可以有多个挂号订单，一个订单只属于一个患者

一个号源可以被一个订单占用，一个订单占用一个号源

一个用户对应一个患者

状态码说明

科室状态：

1：正常可用

0：已停用

医生状态：

1：正常出诊

0：已停诊

号源状态：

1：可以预约

0：停止预约

订单状态：

0：待支付（刚挂上号，还没付钱）

1：已支付（付过钱了，等看病）

2：已取消（不想看了，取消了）

3：已就诊（已经看过病了）

时间字段说明

period字段：

1：上午时段（通常是8:00-12:00）

2：下午时段（通常是13:00-17:00）

使用示例

查询所有可预约科室：

SELECT * FROM department WHERE status = 1 ORDER BY sort_order;

查询内科的医生：

SELECT * FROM doctor WHERE dept_id = 1 AND status = 1;

查询张明医生的可预约时间：

SELECT * FROM registration_source WHERE doctor_id = 1 AND status = 1 AND work_date >= CURDATE() ORDER BY work_date, period;

用户登录验证：

SELECT * FROM sys_user WHERE username = 'zhangsan' AND password = 'e10adc3949ba59abbe56e057f20f883e';

创建挂号订单（需要按顺序操作）：

检查号源是否可约

减少号源的available_count

生成订单号

创建订单记录

取消挂号订单：

更新订单状态为已取消

增加号源的available_count

注意事项

挂号时一定要先检查available_count是否大于0

减少available_count和创建订单最好在一个事务中完成

同一个医生的同一个日期和时段不能重复创建号源

患者的手机号必须是唯一的

订单号是系统自动生成的，不要手动填写
